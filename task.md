# Open Scanner — Chuqur Audit va Ish Rejasi

> Manba: https://github.com/pencilresearch/OpenScanner (MIT litsenziya, App Store'da mavjud: "Open Scanner").
> Audit sanasi: 2026-07-09. Kod hajmi: ~4600 qator Swift, 26 fayl. Arxitektura: SwiftUI + Core Data + CloudKit, iOS 16.0+ / visionOS 1.2+.
> Xulosa: **kodni asos sifatida olish to'g'ri qaror** — kichik, toza, tashqi bog'liqliklarsiz (0 ta SPM/CocoaPods paket) loyiha. Lekin u "MVP" darajasida: ba'zi funksiyalar yarim tugallangan, dizayn 2022-2024 uslubida (iOS 16 davri), va bir nechta jiddiy bug bor. Pastda hammasi ustuvorlik bo'yicha tartiblangan.

> **Holat (2026-07-11):** **1, 2, 3-bosqich va 4-bosqichning katta qismi bajarildi.** **Face ID/parol himoyasi foydalanuvchi qarori bilan ro'yxatdan butunlay olib tashlandi — kerak emas.** 3-bosqich funksiyalari (rasm filtrlari, imzo, batafsil qidiruv/filtr, teg tizimi) to'liq amalga oshirildi — 3-bo'limga qarang. Asosiy sahifa (HomeView) endi uch marta qayta dizayn qilindi — oxirgisi butunlay yangi "hero card" paradigmasi (to'liq o'lchamdagi sahifa rasmi + suzuvchi belgilar) bilan, 7.1-bo'limga qarang. Qidiruv joylashuvi bug'i, landscape qo'llab-quvvatlash, SF Symbols animatsiyasi, `os.Logger`ga o'tish — barchasi bajarildi.

## 0. Arxitektura xulosasi (nima bor)

- **Ekranlar**: Home (skanlar ro'yxati) → Classic Scan (VisionKit `VNDocumentCameraViewController`, avtomatik chekka aniqlash) yoki Live Scan (`DataScannerViewController`, real vaqtda matn/shtrix-kod aniqlash + avto-suratga olish) → Scan Summary (sahifalarni ko'rish/tahrirlash/ulashish).
- **Ma'lumotlar**: Core Data modeli `Scan → ScanCapture → ScanRecognizedItem` (3 daraja), CloudKit orqali qurilmalar aro sinxronizatsiya.
- **Qidiruv**: CoreSpotlight indekslash (Spotlight'dan skan ochish ishlaydi).
- **Integratsiyalar**: App Intents / Siri Shortcuts, Home Screen + Lock Screen widget, joylashuv (ixtiyoriy), matnni ovozga aylantirish (AVSpeechSynthesizer).
- **Eksport**: PDF (rasm sifatida, OCR matni ko'milmagan — qidirilmaydigan PDF), oddiy .text fayl, tizim share sheet orqali ulashish.
- **Kuchli tomonlari**: bog'liqliklar yo'q (yengil, tez qurish), kod tuzilishi tushunarli (Views/UIKit/Data/Buttons papkalari), VisionKit'dan to'g'ri foydalanish, real ishlaydigan OCR va live-scan.

## 1. KRITIK BUGLAR — birinchi navbatda tuzatish kerak

1. ✅ **BAJARILDI** — **Core Data delete rule = "Nullify", "Cascade" emas.** `Scan` o'chirilganda uning `ScanCapture`/`ScanRecognizedItem` yozuvlari o'chmaydi — faqat `parent = nil` bo'lib, bazada abadiy "etim" (orphan) qoladi, disk hajmini cheksiz o'stiradi. ([scanner.xcdatamodel](scanner/Data/scanner.xcdatamodeld/scanner.xcdatamodel/contents)) → `captures` va `recognizedItems` munosabatlari **Cascade**ga o'zgartirildi (migratsiya shart emas — delete rule SQLite sxemasining qismi emas, faqat Core Data runtime xatti-harakati).
2. ✅ **BAJARILDI (3-bosqichda)** — **Widget butunlay ishlamas edi — sabab kutilganidan chuqurroq ekan.** Uchta alohida muammo topildi va barchasi tuzatildi: (a) `TimelineProvider` fetch natijasini tashlab yuborardi — endi haqiqiy skanlar soni va nomlari `ScanArrayEntry`ga o'tadi; (b) `WidgetView` hech qachon `entry`dan foydalanmasdi (doim statik "Classic" matni) — endi skanlar sonini ko'rsatadi ("N scans"/"Start scanning"), lock-screen doira widget'i uchun `AccessoryWidgetBackground()` qo'shildi; (c) **eng muhimi**: widget extension'da App Group/iCloud entitlements **umuman yo'q edi** va asosiy ilova ma'lumotlar bazasini umumiy App Group papkasida saqlamas edi — shuning uchun widget hech qachon asosiy ilova ma'lumotini ko'ra olmasdi. Simulyatorda `scanner.sqlite` haqiqatan shu umumiy papkada yaratilgani fayl tizimi orqali tasdiqlandi.

## 3. YETISHMAYOTGAN FUNKSIYALAR (raqobatchilarga nisbatan)

Bozordagi skanerlash ilovalari (Scanner Pro, Adobe Scan, Microsoft Lens va h.k.) bilan solishtirganda yetishmayotganlar:

- [x] ✅ **BAJARILDI** — **Qidirilishi mumkin bo'lgan PDF (searchable PDF)**. `pdfDocument()` endi har bir sahifa uchun rasm ustiga Vision OCR orqali aniqlangan matnni **ko'rinmas qatlam** sifatida (`CGContext.setTextDrawingMode(.invisible)`) to'g'ri joylashtiradi — natijada PDF vizual jihatdan bir xil ko'rinadi, lekin matni qidiriladigan va tanlanadigan bo'ladi. Buni haqiqiy avtomatik test bilan tasdiqladim: sun'iy matnli rasm yaratib, eksport qilingan PDF'ning `.string` xossasi kutilgan matnni o'z ichiga olishini tekshiradigan `testSearchablePDFExportContainsRecognizableText` testi yozildi va **muvaffaqiyatli o'tdi**. (Bonus: shu jarayonda loyihaning test sxemasi ham tuzatildi — `scannerTests` avval umuman ishga tushmas edi, chunki `.xcscheme` faylida Test Action bo'sh edi.)
- [x] ✅ **BAJARILDI** — **Rasm filtrlari**. Yangi `ScanImageFilter` enum ([ViewExtensions.swift](scanner/Extensions/ViewExtensions.swift)) — `Original`, `Enhanced` (kontrast/to'yinganlik biroz oshirilgan), `Grayscale` (`CIPhotoEffectMono`), `Black & White` (to'yinganlik 0 + kuchli kontrast — haqiqiy "qog'oz skaner" ko'rinishi) — CoreImage (`CIFilter`) orqali amalga oshirildi. Har bir skan sahifasini uzoq bosish (long-press) orqali chiqadigan menyu (`.scanFilterMenu(for:)`) — ham Classic Scan ro'yxatida ([LiveScanSummary.swift](scanner/Views/LiveScanSummary.swift)), ham Live Scan tasmasida ([LiveCaptureSummary.swift](scanner/Views/LiveCaptureSummary.swift)) qo'shildi. **Nodestruktiv**: `ScanCapture`ga yangi `originalImageData`/`filterName` Core Data atributlari qo'shildi (lightweight migratsiya — ikkalasi ham optional/binary, CloudKit talabiga mos) — filtr birinchi marta qo'llanganda asl (filtrlanmagan) rasm alohida saqlanadi, shu sababli foydalanuvchi istalgan vaqt filtrni almashtirishi yoki "Original"ga qaytishi mumkin, sifat yo'qotmasdan. Build muvaffaqiyatli tekshirildi (`BUILD SUCCEEDED`, asosiy ilova + widget extension target ikkalasi ham). **Ochiq qoldi**: uzoq-bosish menyusining real qurilmada/simulyatorda qo'lda tegishni tekshirish (headless muhitda long-press ishonchli simulyatsiya qilinmaydi).
