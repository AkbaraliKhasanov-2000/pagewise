# Pagewise

Pagewise is a fast document scanning app for iPhone. It saves your scans into its built-in library and syncs them across your devices via iCloud.

## About the app

### What is Pagewise?

Pagewise scans your receipts, notes, textbooks, and anything else you point your iPhone at, using on-device OCR to make the text searchable and copyable.

### What permissions does Pagewise ask for?

Pagewise will prompt you for the following permissions:

 - **Camera**: Required for scanning your documents.
 - **Location**: Optional. If you grant location permission, Pagewise will annotate your scans with location data.

### What data does Pagewise collect?

Scans are stored in iCloud (via CloudKit) under your own Apple ID and are not sent to any third-party server. A dedicated privacy policy will be published before release.

## About this project

Pagewise is written in Swift and built with SwiftUI. It uses Core Data for data storage and CloudKit for synchronization. It supports iOS 16.0+ and visionOS 1.2+.
